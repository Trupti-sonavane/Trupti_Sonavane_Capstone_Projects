\# Individual Reflection

\## Enterprise Sales Intelligence Dashboard



\### 1. Project Experience



Working on the Enterprise Sales Intelligence Dashboard was a valuable learning experience. This project helped me understand how Business Intelligence tools can be used to transform raw sales data into meaningful business insights.



Throughout the project, I worked on data preparation, data modeling, DAX calculations, dashboard development, and interactive reporting using Microsoft Power BI.



\### 2. Key Learnings



During this project, I gained practical experience in:



\- Understanding and analyzing relational datasets.

\- Cleaning and transforming data using Power Query.

\- Creating relationships between multiple tables.

\- Developing DAX measures and Key Performance Indicators (KPIs).

\- Designing interactive dashboards using Power BI.

\- Implementing Year and Region filters.

\- Creating Drill-through functionality for detailed regional analysis.

\- Implementing and testing Row-Level Security (RLS).

\- Organizing project files and documentation using GitHub.



\### 3. Challenges Faced



Some of the major challenges encountered during the project included:



\- Understanding relationships between multiple data tables.

\- Writing accurate DAX measures for business calculations.

\- Resolving issues related to date-based calculations.

\- Designing meaningful and user-friendly dashboard visualizations.

\- Configuring interactive filters and Drill-through functionality.

\- Implementing and validating Row-Level Security.



These challenges helped me improve my problem-solving and analytical skills.

\### 5. Overall Learning Outcome



This project provided practical exposure to the end-to-end Business Intelligence development process, from understanding raw data to building an interactive analytical dashboard.



I gained confidence in using Power BI to analyze business data, develop KPIs, and present insights through visual reports.

In future projects, I aim to explore advanced analytics, predictive modeling, automated data pipelines, cloud-based deployment, and real-time data integration to build more scalable Business Intelligence solutions.
